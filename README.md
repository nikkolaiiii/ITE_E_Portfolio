# Nikkolai Yabut | ITE Portfolio

A responsive, view-only student portfolio for GitHub Pages with Home, Contents, Prelim, Midterm, Final, Reflection, and Profile sections.

## Run locally

Open this folder in VS Code and run Live Server from `index.html`, or serve the folder with any static HTTP server. The portfolio reads its published entries from `portfolio-data.json`, so opening the HTML directly through a `file://` URL will not load the course data.

## Portfolio data

The Prelim, Midterm, and Final sections display the entries and attachments stored in `portfolio-data.json`. This file is the published source of truth, so visitors see the same entries on any browser or device. The deployed site is view-only; it has no upload forms or browser-only draft storage.

## GitHub Pages

The live site is published from the repository's `main` branch root at:

`https://nikkolaiiii.github.io/ITE_E_Portfolio/`
